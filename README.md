# Gym Tracker — офлайн PWA

## Что это
Устанавливаемое веб-приложение для iPhone и Android. После первой загрузки и установки интерфейс открывается без интернета. Записи хранятся локально в IndexedDB отдельно на каждом устройстве; автоматической синхронизации между телефонами нет.

## Публикация (нужна один раз, с интернетом)
PWA нельзя установить из ZIP-файла напрямую. Сначала разместите эту папку на HTTPS-хостинге (например, GitHub Pages или Netlify). После первой загрузки откройте приложение и установите его.

### GitHub Pages
1. Создайте репозиторий GitHub (можно Private, но для GitHub Pages на бесплатном тарифе обычно нужен Public).
2. Загрузите `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`.
3. В Settings → Pages выберите Deploy from a branch, ветка `main`, папка `/ (root)`, сохраните.
4. Дождитесь адреса `https://<username>.github.io/<repository>/`.

## Установка
- iPhone: откройте адрес в Safari → Поделиться → На экран «Домой» → Добавить.
- Android: откройте адрес в Chrome → меню ⋮ → Установить приложение / Добавить на главный экран.

## Офлайн
Первый визит и установка требуют интернет-соединения, чтобы браузер скачал приложение и кэш. После успешной загрузки откройте приложение один раз, дождитесь загрузки, затем его оболочка работает офлайн. Все данные хранятся локально на устройстве.

## Резервная копия
Внизу приложения есть «Экспорт данных» и «Импорт данных». Экспортируйте резервную копию регулярно. Для переноса данных на другой телефон экспортируйте JSON на старом устройстве и импортируйте его на новом.

## Важно
Удаление данных сайта/приложения или самого приложения может удалить локальные записи. Храните резервные копии отдельно. Это офлайн-приложение не синхронизирует записи между iPhone и Android.
